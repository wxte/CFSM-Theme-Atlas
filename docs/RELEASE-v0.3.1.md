# v0.3.1 交付说明

基于 2026-09-08 下载的 wxte/cfsm-line-grid main（package.json v0.3.0）。仅修改本地副本，未向 GitHub 写入。

## Drawer 定位与修复

原截图的红色不规则笔画外观更像手绘标注，不能仅凭截图认定是网页绘制。检查 v0.3.0 DOM，资源卡仅有 small/strong 文本，不含 SVG 或折线；CSS 也没有在该区域绘制红线的规则。
确定的布局问题是五个项目的两列网格：nth-last-child(-n+2) 同时移除了 RAM 和 DISK 底边，而最后一个 DISK 跨两列，造成 RAM 下方边界缺失。改为只移除最后一项底边，并将选择器限定到直接子项，避免未来嵌套图表继承边框。
另修复首次打开时 syncDrawer 在 hidden=true 下直接返回，以及关闭动画计时器误关闭刚重开的 Drawer。

## 功能盘点

| 功能 | 本轮结果 |
|---|---|
| Lucide 风格统一图标 | 保留已有本地线性 SVG；没有引入完整 Lucide 库，不宣称这些是官方 Lucide 资产 |
| SVG 圆旗 | 现有本地矩形 SVG 保留；圆旗暂缓，以避免简单裁切破坏旗帜图案 |
| 节点 Sparkline | 新增 CPU、下行、上行；当前会话最近60次真实资源上报，缺指标/超过5分钟间隔断线，不用 DOM 重绘伪造采样 |
| 60 格 Tracker | 新增节点及 Drawer 最近60条实际网络观测；不足60条用无数据补位，鼠标/触控/方向键查看三网与丢包 |
| Command Palette | 已有，保留 Ctrl+K、搜索、快捷命令 |
| Drawer | 保留桌面侧栏、手机底部抽屉，修复布局和生命周期 |
| Toast、Skeleton、相对更新时间 | 已有并保留 |
| Animated Terminal | 暂缓，纯装饰优先级低 |
| 时间范围 | 新增网络页 1H/2H，曲线、横轴及取样同步切换；现有历史缓存上限2小时，6H/24H/7D需后端能力确认后再做 |

Tracker 表示网络观测，不代表连续在线率；100%丢包不能等同于节点离线。网络历史保持原有30秒降采样策略，保留观测原始时间；状态格不是每秒生成的历史。资源 Sparkline 刷新页面后重新收集，未持久化。首次进入等待真实 WebSocket 资源上报。

## 安装

将完整 ZIP 解压，把其中内容覆盖仓库根目录即可。无需运行旧 apply-v0.3.0.mjs；该旧脚本保留作历史资料，重新执行会回退版本信息。所有运行时缓存 URL 已统一为 v0.3.1。

仍为原生 JS/CSS，无 React/Vue，无新增依赖或外部 CDN。根目录 enhancements 文件与 assets 运行时副本同步。
