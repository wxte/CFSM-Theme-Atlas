# WXT Atlas v0.3.7 · 微图与视觉细化

适用基线：v0.3.6。此包仅包含新增、修改的文件，保留仓库目录，解压后覆盖对应文件即可。无需删除文件，不运行旧版 apply 脚本。

## 改动

- 详情内的 CPU、上下行微图采用细曲线、轻渐变填充和末端点；增加当前数值。保持概览紧凑尺寸，图表仍按需显示在行内折叠详情中。
- 资源曲线采用有界控制点，经过真实采样点，不产生超出相邻采样值的额外峰谷。缺失指标与长时间断报会同时切断线条及填充。
- 可见资源微图的新数据采用 260ms 过渡，共用一个动画调度循环。无数据、断点、密集长历史及首次绘制直接显示；隐藏标签页、收起详情或滚出视口后结束动画。
- 延迟图保留原始折线和尖峰，仅细化线宽、渐变填充和末端点，不对延迟数值做平滑处理。
- 统一卡片边框、轻底色、表头、按钮与提示样式，减少 Toast 的模糊开销。
- 移除站内动态效果按钮、对应命令和旧设置的读取；系统级减少动态效果偏好仍自动生效，无需站内操作。
- 不修改后端、Agent、网卡、流量累计或重置方式；无新增第三方依赖或外部 CDN。

## 验证

- npm test：32 项通过；npm run check：通过。
- 浏览器模拟实时上报：确认曲线、渐变、当前值、末端点和更新动画显示正常；详情关闭后没有持续运行的微图动画。
- 检查桌面、390px 与 320px，明暗主题、管理后台入口、无横向溢出、网络 1H 切换与方向键锁定。
- 浏览器控制台未出现运行错误。保留 v0.3.6 的 24 段网络状态条与选中状态逻辑。

## 文件范围

新增 assets/plot.js 和 tests/plot.test.js。其余变更为相关前端模块、样式、index.html、版本信息和说明文档。增量包由与 v0.3.6 逐文件比较生成，不包含 node_modules 或未修改文件。
