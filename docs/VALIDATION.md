- 浏览器标题在初始加载、接口完成、切换视图后均为 `WXT Atlas · Cloudflare Server Monitor`。
- 网络页仅显示网络视图，资源页仅显示资源视图；概览保留 KPI、地区 / 地球 / 网络摘要与节点表。点击导航不触发锚点滚动，前进 / 后退恢复对应视图。
- 375、390、800、1024、1440 像素宽度无页面横向溢出。手机地区 / 网络面板默认折叠；桌面自动展开。
- 桌面日间与手机夜间截图检查通过，状态圆点含实心中心与浅色圆环，手机流量 / 运行时间并排。
- 地区筛选、名称搜索、空结果清除筛选、详情展开、切换视图保留筛选与详情、显示设置持久化、地球关闭与恢复已检查。
- Console 未捕获应用警告或错误。真实节点数值持续变化，顶部实时连接状态正常。

## 限制

- 地球点位默认使用地区中心；只有已有主题配置提供连接关系时才画连接线。
