# WXT Atlas v0.3.6

## 界面

- 压缩概览卡片的间距、数字行高和说明区留白；资源卡片使用统一中文标签。
- 网络状态条最多显示 24 段，合并相邻真实采样。组内出现完全丢包或高延迟时保留异常颜色；真实缺失指标仍显示未知状态，不生成空采样。
- 状态条变为较细的圆角色段，保留 24px 桌面 / 28px 手机点击区域。支持点击、左右方向键、Home、End 与 Esc。
- 改善手机双列概览、费用换行、流量余量文字与暗色显示。
- 用“本周期流量”说明节点自己的重置周期，用“月费折算”说明费用按周期折算且不同币种分别汇总。
- 保留原有行内折叠详情、按需创建图表和手机管理后台入口。

## 性能与交互

- 同一帧到达的实时消息合并渲染，网络页不再同步渲染隐藏的节点列表和概览图。
- 鼠标停留在同一个采样点时不重复更新提示；丢包标记复用一个 SVG path。
- 网络历史加载期间保留已锁定采样，切回节点页立即同步最新值。
- 修复首次通过 #overview 打开页面时，浏览器原生锚点滚动可能遮住概览标题的问题。

## 验证

- npm test：29 项通过；npm run check：通过。
- Chrome 模拟数据浏览器检查：1440、768、390、320px；亮色/暗色、无横向溢出、1H/2H/24H 切换、7D 未登录提示、选中状态刷新恢复、方向键、返回节点页更新。
- 单独验证 1440、390、320px 的行内详情开关、图表按需创建、流量进度、手机后台链接及实时更新后的焦点保留。
- 同一组 8 节点模拟数据，1440px 下概览两排卡片区域由 318.6px 降到 233.6px，约减少 27%。
- 8 节点 × 3 条线路的状态按钮上限由 1440 降至 576，减少 60%。
- 连续 20 条仅 CPU 更新的模拟消息没有引起网络图 DOM 变更。这是局部渲染验证，不代表所有设备的帧率或总 CPU 占用降低相同比例。

## 安装与范围

将压缩包内容覆盖主题仓库根目录，然后重新应用主题。包内已经是完整成品，不要再次运行旧版 apply-v0.3.0.mjs。

此版本只修改主题；不修改 Agent、后端、网卡配置、流量校正或重置逻辑。流量字段与计算方式保持 v0.3.5 原样。压缩包不含 node_modules。未直接修改 GitHub 或线上部署。
